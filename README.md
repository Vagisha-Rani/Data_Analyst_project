## 8. How to Run the Project

Follow these steps to execute the project:

**Prerequisites:**
- Python 3.x
- Jupyter Notebook
- PostgreSQL / MySQL / SQL Server
- Power BI Desktop

**Execution Steps:**

1. Clone this repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd Data-Analytics-Project
   ```

3. Install the required Python libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn jupyter
   ```

4. Open Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

5. Run the Python notebooks in the following order:
   - Data Loading
   - Exploratory Data Analysis
   - Data Cleaning

6. Import the cleaned dataset into your SQL database.

7. Execute the SQL queries provided in the SQL folder.

8. Open the Power BI `.pbix` file to explore the interactive dashboard.

9. Review the project report and Gamma AI presentation.
